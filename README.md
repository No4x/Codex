# Codex

> 个人 AI 助手技能（Skill）工具箱 —— 把反复用到的工作流固化成「可被助手直接执行的文档 + 脚本」。

本仓库用来存放我为 AI 助手（Codex / WorkBuddy 等）编写的**可复用技能包**。每个技能把一套原本需要临场摸索的多步流程，
写成一份 `SKILL.md` 加上配套脚本与参考资料，让助手下次**照着步骤执行**，而不是每次重新试错。

主要来源是我的教学与教研工作（高职《电气控制技术实训》等课程的课件重构），也包含一些工具型技能。

## 内容按分支组织

`main` 分支只保留这份说明文件；**每个技能单独放在一个 `feature/<技能名>` 分支上**。
这样各技能的迭代历史互不干扰，也方便单独 review、单独合并。

```
skills/
└── <skill-name>/
    ├── SKILL.md        # 技能主文档：何时用 / 何时不用 / 执行步骤 / 注意事项
    ├── references/     # 参考资料（行业规范、踩坑总表等）—— 可选
    ├── scripts/        # 可直接运行的脚本 —— 可选
    └── agents/         # 助手平台适配配置 —— 可选
```

## 使用方式

1. 切到对应分支，取 `skills/<skill-name>/` 整个目录；
2. 放进助手的技能目录（例如 `~/.workbuddy/skills/<skill-name>/`）；
3. 之后在对话里提到对应场景，助手会按 `SKILL.md` 的步骤执行。

技能包内脚本均为**单文件、零外部服务依赖**，只依赖标准库或说明中列明的第三方包。

## 约定

- 一个技能一个分支，分支名统一为 `feature/<skill-name>`；
- 脚本不写死本机绝对路径，运行参数与依赖写在 `SKILL.md` 里；
- 引用外部资料注明来源；参数、引用、数据不确定时标注为待确认，**不臆造**。
