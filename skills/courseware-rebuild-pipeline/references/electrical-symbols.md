## 1 · 触点：静触点横线 + 动触点斜刀

### 1.1 唯一合法画法

```
静触点 = 与引线【垂直】的短横线
         引线竖向 → 横线水平；引线横向 → 横线竖直
动触点 = 从引线端点斜出的【刀】
```

### 1.2 常开（断开）

刀翘起，**刀尖沿引线方向差 10–18px** 才碰到静触点横线 → 视觉上明显不接触。

```xml
<!-- 水平引线 + 竖向静触点横线；动触点刀翘起（差 14px） -->
<line x1="91"  y1="410" x2="161" y2="410" stroke="#1D4ED8" stroke-width="2.4"/>   <!-- 左引线 -->
<line x1="161" y1="410" x2="227" y2="374" stroke="#94A3B8" stroke-width="3"
      stroke-linecap="round"/>                                                     <!-- 动触点刀（翘起） -->
<line x1="241" y1="392" x2="241" y2="428" stroke="#1D4ED8" stroke-width="2.4"/>   <!-- 竖向静触点横线 -->
<line x1="241" y1="410" x2="311" y2="410" stroke="#1D4ED8" stroke-width="2.4"/>   <!-- 右引线 -->
```

> 静触点横线 x=241（中心线 y=410），刀尖落在 x=227 → **差 14px**，未相接 = 常开。

### 1.3 常闭（接通）

刀**搭过**静触点横线，**刀尖超出横线 6–10px**。

```xml
<line x1="435" y1="410" x2="527" y2="392" stroke="#059669" stroke-width="3"/>     <!-- 刀搭过 x=515 -->
<line x1="515" y1="392" x2="515" y2="428" stroke="#1D4ED8" stroke-width="2.4"/>   <!-- 静触点横线 x=515 -->
```

### 1.4 斜刀角度

刀与引线的夹角控制在 **25°–32°**。
实测小于 20° 时观感像一条横线，学生会认成断开或直接忽略。

参考坐标（本册采用）：

| 用途 | 起点 → 终点 | 角度 |
|---|---|---|
| P29 主触点常开 | `216,332 → 231,358` | Δx15 / Δy26 ≈ 30° |
| P29 辅助常开 | `360,432 → 377,462` | ≈ 30° |
| P42 延时常开 | `154,316 → 196,292` | ≈ 30° |
| P47 按钮常开 | `142,302 → 190,280` | ≈ 30° |

### 1.5 严禁

- ❌ **「圆点＋斜刀」** —— 不代表任何标准触点（本项目首版 P09 就是这么画的，必须改）
- ❌ **「十字形」** —— 长引线中间夹一条短横线，不代表任何触点（首版 P29/P31/P32 共 4 处）
- ❌ **同册两套画法** —— 如一页用「圆点＋斜刀」、另一页用「横线＋斜刀」，学生跨页对照会困惑
- ✅ 一册之内**只有一种**触点画法

## 2 · 断路器 QF（带脱扣标记的三极开关）

结构 = **三极斜刀** + **每极脱扣标记 `×`** + **一条水平联动虚线**。

```
每极：  上引线  ──  ×（脱扣标记，画在引线旁）  ──  斜刀  ──  下引线
三极：  并列三组，等距
联动：  一条 stroke-dasharray="6 5" 的水平虚线横穿三极（表示机械联动）
文字：  「带脱扣标记的三极开关」
```

```xml
<!-- 联动虚线 -->
<line x1="120" y1="300" x2="300" y2="300" stroke="#1D4ED8" stroke-width="1.6"
      stroke-dasharray="6 5"/>
<!-- 每极的脱扣标记 ×（用两条短线拼） -->
<line x1="128" y1="252" x2="140" y2="264" stroke="#1D4ED8" stroke-width="2"/>
<line x1="140" y1="252" x2="128" y2="264" stroke="#1D4ED8" stroke-width="2"/>
```

> 幅面紧张时，先把旁边的元件**方块**缩小让位（本册 P14 把 96×96 的 QF 方块缩为 72×72）。

## 3 · 行程开关 / 限位开关 SQ

教材参照图 `images/image52.png` 给出三种：**常开 / 常闭 / 复合（一体）**。
竖引线 + 斜刀，文字标注 `SQ`。三种符号的差异**只在刀与静触点横线的相对位置**，画法同上。

---

## 4 · 按钮 SB

- 操动件（按钮帽）画成**开口矩形 / 半圆**，与触点之间用**虚线**连接（表示机械联动）
- 常开触点：刀翘起；常闭触点：刀搭过
- 颜色规定：`绿=启动 / 红=停止 / 黑=通用`（本册 P47 有专门一页讲颜色与端子编号）

---

## 5 · 熔断器 FU

**矩形中带一条贯穿线**（贯穿方向 = 电流方向）。
不要画成「圆角方框 + 无名扁矩形」两块叠放（首版 P32 接线图就是这个形态，性质不明确，未擅改）。

## 6 · 审计流程（改符号前必做）

```python
# 1) 统计：解析全册 SVG 的 <line>/<circle>/<path>，按方向分类
#    水平 (y1==y2) / 垂直 (x1==x2) / 斜线 —— 斜线与短线密集区即为自绘符号页
# 2) 逐页读源码，定位 <g id="symbol-*"> 组
# 3) 无头浏览器渲染 → PIL 裁剪放大到 4× 目视
# 4) 与教材参照图对照
```

**产出必须是一份「自绘符号页清单」**（本项目为 **P09 / P14 / P20 / P29 / P31 / P42 / P47**）。
清单之外的页（教材扫描图 `user` 来源）**改版时不要动**。

**可复用脚本**：`scripts/scan_contact_symbols.py`（按几何特征找「长竖线中间夹短横线」的十字错误，
注意排除时序图竖轴上的刻度短线，本项目 18 处命中里 14 处是误报）。
